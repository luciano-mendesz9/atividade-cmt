💡 Por que usar INPUT_PULLUP?

O Arduino ativa um resistor interno que mantém a entrada em nível alto quando o botão está solto. Ao pressionar, o botão conecta o pino ao GND e a leitura vira LOW. Por isso, não precisamos de resistores extras nos botões.

🔎 Como evitar o erro mais comum?

Alguns terminais do mesmo botão já são conectados internamente. Se você ligar GND e o pino digital ao mesmo par, o Arduino poderá ler o botão como pressionado o tempo todo. Use terminais de pares diferentes.

Precisa de ajuda? Revelar um código completo que funciona

Este exemplo usa LOW para detectar o botão pressionado porque configuramos INPUT_PULLUP. Observe que existem dois if/else independentes, permitindo as duas luzes acesas ao mesmo tempo.

const int B1 = 2;
const int B2 = 3;
const int LED_VERDE = 8;
const int LED_AZUL = 9;

void setup() {
  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_AZUL, OUTPUT);
  pinMode(B1, INPUT_PULLUP);
  pinMode(B2, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(B1) == LOW) {
    digitalWrite(LED_VERDE, HIGH);
  } else {
    digitalWrite(LED_VERDE, LOW);
  }

  if (digitalRead(B2) == LOW) {
    digitalWrite(LED_AZUL, HIGH);
  } else {
    digitalWrite(LED_AZUL, LOW);
  }
}
